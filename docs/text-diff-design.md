# 「文本对比」功能设计（TXT 对比工具）

## 一、调研：主流对比软件的功能

### WinMerge（Windows 开源标杆，官网功能页确认）

- 双栏（及三方）并排对比，行级差异着色 + **行内字符级差异高亮**
- 直接在两栏中编辑文本，差异实时刷新
- **同步滚动 + 定位窗格**（Location Pane 概览条）、差异上/下一处跳转
- 移动行检测（Moved lines detection）
- 忽略选项：大小写、空白、行尾符；正则文件过滤器
- 差异操作：复制左到右 / 右到左、合并窗格、生成补丁（unified diff）
- 行号、语法高亮、自动换行、统计差异数量

### Beyond Compare（商业标杆）

- 规则化对比（忽略空白、注释等自定义规则），左右双栏 + 行内高亮
- 对齐块手动拖动（misaligned block 手动对齐）
- 会话式保存（记住忽略选项）、文件夹/文本/十六进制多种模式
- 合并视图（3 栏中间为合并结果）、差异导航、统计

### Meld（Linux）

- 三方对比与合并，行内高亮，编辑即时重算，Use A/B 操作按钮

### VS Code 对比视图

- 双栏 + 可切换行内（inline）视图；**差异字级高亮**；边栏 diff 标记条（绿/红）；接受/放弃修改按钮；**两侧均可编辑并实时重算**；忽略空白/大小写开关

### Notepad++ Compare 插件

- 双栏同步滚动、字符级差异着色、Swap（交换左右）、F7 跳转差异、忽略设置

### 共性结论（必须项）

| 能力 | 说明 |
| --- | --- |
| 双栏并排 + 行级着色 | 红（左独有/删除）、绿（右独有/新增）、黄（修改） |
| 行内字符级差异高亮 | 修改行内部再对比一遍，标出具体字符 |
| 同步滚动 | 两栏滚动位置按差异对齐联动 |
| 差异导航 | 上一处/下一处跳转 + 总差异数统计 |
| 双侧可编辑 | 编辑后实时重新对比 |
| 差异操作 | 把一侧的内容应用到另一侧（复制左→右 / 右→左） |
| 忽略选项 | 忽略空白、忽略大小写（可开关） |
| 查找 | 正则查找/替换（WinMerge 的过滤、BC 的规则本质都是正则） |
| 保存 | 保存单侧或合并结果，支持多种文本编码 |

## 二、功能设计（本工具范围）

### 2.1 定位与入口

- 侧边栏「文本处理」分组新增 **「文本对比」**，路由 `/epub-tool/text-diff`
- 输入：两个 TXT 文件（支持 GBK/Big5/UTF-8 自动检测）或直接粘贴文本
- 输出：对比结果视图 + 保存任一栏编辑后的文本

### 2.2 主界面布局

```text
┌───────────────────────────────────────────────────────────┐
│ 页头（图标 + 文本对比 + 说明）                               │
├───────────────────────────────────────────────────────────┤
│ 工具栏: [打开A] [打开B] [保存A] [保存B] │ 忽略空白□ 忽略大小写□ │
│          │ [查找替换] [上一条] [下一条] │ 共 N 处差异           │
├───────────────────────────────────────────────────────────┤
│ 左栏（A）            │   差异条（对齐映射）  │ 右栏（B）        │
│ 行号│文本(高亮)       │   ▓ 差异色块         │ 行号│文本(高亮)  │
│ 行号│文本             │                     │ 行号│文本        │
│ 行号│文本(高亮)       │                     │ 行号│文本(高亮)   │
│ ...（同步滚动）       │                     │ ...（同步滚动）  │
├───────────────────────────────────────────────────────────┤
│ 底部操作栏：保存合并 / 统计信息                              │
└───────────────────────────────────────────────────────────┘
```

### 2.3 核心功能规格

#### ① 对比与高亮

- **行级差异**：左独有（红）、右独有（绿）、修改（黄/橙双色分别标识左右两侧）
- **字符级差异**：对"修改"行对做二次对比，行内标出具体变化的字符段（底色加深）
- 对比选项（切换后立即重算）：**空白模式**（不忽略 / 忽略行首尾空白 / 忽略行尾空白 / 忽略全部空白）、**忽略空白行**（默认开启：多余的空白行不输出，可关闭后纳入差异）、**相似度阈值**（仅精确匹配 / ≥50% / ≥70% / ≥90%，用于哈希不等但内容相近的行配对）、忽略大小写
- 差异导航：上一条/下一条跳转并滚动到可视区居中，当前差异加边框强调
- 概览条（可选增强）：两栏中间细长条，色块概览全文差异分布，点击跳转

#### ② 同步滚动

- 两栏共享**统一行模型**：diff 结果输出左右两栏共用的行列表（`rows`），一行对应两侧各一条（单侧独有行为空占位），两栏 ListView 的 itemCount 与 itemExtent 完全一致
- 任一栏滚动 → 把同一偏移量同步到另一栏（`jumpTo`，带防回环标志），**两侧滚动进度天然一致**；行内字符差异与查找高亮都基于该行模型渲染
- 单侧独有段落：该段在另一侧渲染为空占位行（浅灰背景），较长一侧自由滚动，另一侧同步推进——段落数量不同时进度依然以行为单位对齐
- 横向滚动：每行内嵌共享 ScrollController 的横向滚动，两栏文本长行同步横向移动
- 编辑导致行数变化时行模型随 diff 重算自动更新

> 早期方案为「行映射 + 最近锚点 + 间隙插值」，实现后改用统一行模型：
> 复杂度更低、滚动进度两侧完全一致，且空占位渲染与主流对比工具一致。

#### ③ 编辑文件

- 每栏为「行列表编辑器」：逐行渲染（行号 + 高亮 TextSpan），**点击任意行弹出单行编辑**，回车/失焦保存并触发重新对比
- 提供「整文编辑」模式：切换为全文本 TextField（当前栏），编辑后失焦即重算 diff
- 编辑后两侧任一变化 → 防抖（300ms）重新 diff，差异与导航即时更新

#### ④ 差异操作（替换不同点）

- 选中某条差异后，工具栏/右键菜单提供：
  - **复制到右侧**（用左侧内容替换右侧对应行）
  - **复制到左侧**（反向）
  - **忽略该差异**（加入忽略行集合，后续对比不视为差异；可一键清除忽略）
- 批量：支持「全部复制到右侧 / 全部复制到左侧」（按当前忽略/筛选后的差异集）

#### ⑤ 正则查找替换

- 展开面板：查找输入框 + 正则开关 + 替换输入框 + 「上一个/下一个/全部替换/逐个替换」
- 匹配范围：当前栏或两侧同时；匹配行在文本中叠加高亮标记（区别于差异色）
- 正则：Dart `RegExp`（支持捕获组，替换串支持 `$1` 引用）
- 替换执行后自动重新对比，日志面板（复用 OutputLog）记录替换数量与位置

#### ⑥ 文件读写

- 导入：`file_picker` 选 .txt（可多选一次导入两个）；**编码自动检测**（复用 `encoding_detector` + `enough_convert`，支持 UTF-8/GBK/Big5），检测失败回退 UTF-8 并提示
- 保存：保存 A / 保存 B 到原路径或另存为（`file_service`），保留原编码（或统一 UTF-8，提供选项）
- 粘贴输入：两栏各有一个「粘贴文本」入口（替代导入）

### 2.4 技术方案

#### Diff 算法（纯 Dart，`diff_engine.dart`）

重构为 **notepad--（CCompare）同款对比架构**（国产开源编辑器 notepad-- 的代码对比功能即此方案）：

- **行指纹哈希**：每行先归一化（空白模式 / 大小写）→ 计算 64 位哈希（双 32 位 djb2 变体，乘法上界 < 2^39，Web 精度安全），哈希比较代替逐行全文比较
- **锚点切分（块间粗匹配）**：贪心哈希匹配提取公共行作为锚点，将两个文件切成块对
- **块内行配对（对应上游 BlockCompare::lessCmpMore）**：少行对多行，按字符二元组 Dice 系数计算相似度，达到阈值（50/70/90%，默认仅精确匹配）即配对为修改行；未配对行按位置相邻配对为修改 / 新增 / 删除
- **字符级 LCS**：Hirschberg 线性空间分治（非递归栈实现，内存 O(m)），输出行内相等/不等片段（SectionNode），行尾（\r）单独标记相等状态——CRLF 文件行内对比不丢精度
- **空白处理 = 哈希预处理**：四种模式（不忽略 / 忽略行首尾空白 / 忽略行尾空白 / 忽略全部空白），与 notepad-- 三种空白规则同款
- **空白行分离**：空白行默认不参与锚点匹配，左右空白行按顺序配对显示，单侧多余的空白行直接不输出——避免海量空行拖慢对比，也不再有空白行差异干扰阅读
- 大文件（>3000 行）：控制器按块在 Isolate 中渐进计算（`runBackgroundTask`），编辑防抖后仍走后台，UI 显示进度
- 忽略规则在比较前对行做归一化（不影响原始文本，只影响比较）

#### 数据结构

```dart
// diff_engine.dart
enum DiffOp { equal, replace, delete, insert, unknown } // replace = 修改（未配对行相邻配对 / 相似度匹配行）
enum WhiteSpaceMode { exact, trim, trimEnd, all }        // 空白处理模式

class DiffOptions {
  final WhiteSpaceMode whitespaceMode;  // 空白模式（默认 exact）
  final bool ignoreCase;                // 忽略大小写
  final bool ignoreBlankLines;         // 忽略空白行差异（默认开启）
  final int similarityThreshold;        // 相似度阈值 0/50/70/90（0 = 仅精确匹配）
}

class DiffRow {                         // 统一行模型：一行对应左右两栏各一条
  final int? leftIndex;                 // 左栏行号（null = 右侧独有行）
  final int? rightIndex;                // 右栏行号（null = 左侧独有行）
  final DiffOp op;
  final String? leftText; final String? rightText;
  final List<CharSpan>? leftSpans;      // 行内字符级差异段（仅 replace 行）
  final List<CharSpan>? rightSpans;
}

class DiffResult {
  final List<DiffRow> rows;             // 左右两栏共用，行号即滚动锚点
  final List<DiffBlock> blocks;         // 差异块（导航用）
  int get changeCount;                  // 差异处数
}
```

### 2.5 实施阶段

- **P1 基础对比**：diff_engine（行级+字符级 Myers）、双栏高亮视图、统计与差异导航、同步滚动、忽略选项
- **P2 编辑与差异操作**：行编辑弹窗、整文编辑模式、复制左↔右、忽略该差异、保存 A/B
- **P3 正则查找替换**：查找面板、正则匹配高亮、全部/逐个替换、替换日志
- **P4 打磨**：大文件 Isolate、粘贴输入、编码检测接入、概览条、文件拖拽（FileDropTarget）

## 三、关键决策记录

1. **对比引擎采用 notepad--（CCompare）架构而非 Myers**：原实现为行级 Myers O(ND) + trace 回溯，trace 表随差异数增长（几乎完全不同的 1 万行文件会达到数 GB 内存峰值）；重构为「行指纹哈希 + 锚点切分 + 块内相似度配对 + 字符级 Hirschberg 线性空间 LCS」，哈希 O(1) 比较、锚点把对比限制在局部块、字符级回溯内存 O(m)——大文件对比更稳更快，并天然支持渐进分块。
2. **不采用 WebView 渲染编辑器**（TXT 对比用原生控件即可），避免引入 webview 依赖的复杂度；行列表 + TextSpan 高亮性能足够（数千行可滚动列表按需构建）。
3. **固定行高 + 横向滚动**而非自动换行：保证两栏行高一致，同步滚动按行号换算像素，实现简单可靠；文本较长时横向滚动查看（移动端可后续加自动换行+锚点对齐）。
4. **差异色沿用 TDesign 语义色**：红（删除/左独有）、绿（新增/右独有）、黄/橙（修改），暗色模式取对应深色变体；字符级差异用同色加深。
5. **替换不破坏原始文件**：所有编辑/替换操作先在内存中执行，只有用户点「保存」才写盘；提供「另存为」。
